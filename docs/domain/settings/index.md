Domain files for platform settings. Open a file only when its concern is relevant.

- [marketplace-settings.md](marketplace-settings.md) — The single set of values an operator tunes, what applies before they tune anything, when a change takes effect, and who may make one. Read it when working on a value that differs between marketplaces, or on the admin settings screen.
- [fees-and-deductions.md](fees-and-deductions.md) — The named rows an operator configures for what is taken off a seller's earnings and what is added to what a buyer pays. Read it when working on commission, tax, a buyer-facing fee, or what a sale leaves each party.
